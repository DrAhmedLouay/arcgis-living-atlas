مخطط 2: التحويل التوافقي المحافظ (Conformal Similarity) مقابل التحويل التآلفي المشوه (Affine Skew)

التحويل التآلفي العام (Affine) يحتوي على 6 معاملات تسمح بالانحراف الزاوي (Shearing) وتغيير المقياس المستقل بالمحاور (Differential Scaling $s_x \neq s_y$) مما يؤدي لتشويه الخارطة. تم استبداله بتحويل التشابه التوافقي (4 درجات حرية) للحفاظ الصارم على استقامة الزوايا (90°) ونسبة الأبعاد (1:1).

الجداول الفنية والمواصفات القياسية (Technical Specifications)

مقارنات الخوارزميات، بنية ملفات World File، ومطابقة برمجيات GIS

4 جداول مقارنة

جدول 1: مقارنة النماذج الرياضية لمعايرة الخرائط الجغرافية في المنظومة

نموذج التحويل (Transformation) درجات الحرية (DoF) المعادلات الرياضية حفظ الزوايا (90°) حفظ نسبة الأبعاد (1:1) حالة الاستخدام والاعتماد في المنصة
التشابه التوافقي (Conformal Similarity) 4 معاملات (s, θ, tx, ty) x' = s·cos(θ)·x - s·sin(θ)·y + tx
y' = s·sin(θ)·x + s·cos(θ)·y + ty 		نعم (تام ومطلق) نعم (s_x = s_y = s) النموذج القياسي المعتمد في المنصة لمنع تشويه الخرائط المستوردة.
التحويل التآلفي (Affine Transformation) 6 معاملات (a, b, c, d, e, f) x' = a·x + b·y + c
y' = d·x + e·y + f 		لا (يسمح بالانحراف Shearing) لا (تغيير مقياس غير متساوٍ) يستخدم فقط للمعايرات متعددة النقاط (N > 4) عند وجود انكماش ورقي تاريخي.
الإسقاط المنظوري (Projective Homography) 8 معاملات (h11 .. h33) x' = (h11·x + h12·y + h13) / (h31·x + h32·y + 1)
y' = (h21·x + h22·y + h23) / (h31·x + h32·y + 1) 		لا (تلاشي الخطوط المتوازية) لا (تشويه عدسة مائل) مخصص للصور المائلة (Oblique Aerial Imagery) غير المصححة عامودياً.

جدول 2: بنية معاملات مصفوفة ملف الإسناد العالمي ESRI World File (.tfw / .pgw)

السطر رمز المعامل المعنى الهندسي والمكاني القيمة في المنظومة (حالة عدم التدوير) القيمة في المنظومة (مع زاوية تدوير θ)
Line 1 A حجم البكسل باتجاه المحور السيني (X-scale / Pixel Width) +dx +dx · cos(θ)
Line 2 D معامل الدوران والانحراف حول المحور الصادي (Rotation about Y) 0.00000000 -dy · sin(θ)
Line 3 B معامل الدوران والانحراف حول المحور السيني (Rotation about X) 0.00000000 +dx · sin(θ)
Line 4 E حجم البكسل باتجاه المحور الصادي (Y-scale / السالب دائماً من الشمال لأسفل) -dy -dy · cos(θ)
Line 5 C الإحداثي السيني لمركز البكسل العلوي الأيسر (Center of Top-Left Pixel X) Xmin + dx / 2 Xmin + dx / 2
Line 6 F الإحداثي الصادي لمركز البكسل العلوي الأيسر (Center of Top-Left Pixel Y) Ymax - dy / 2 Ymax - dy / 2
💡 ملاحظة جيوديسية حاسمة: تم في التحديث الأخير حل خطأ إزاحة نصف البكسل عبر تصحيح معادلة السطرين الخامس والسادس (`C = Xmin + dx/2` و `F = Ymax - dy/2`) لتلائم معيار مركز البكسل المعتمد في ArcView GIS و ArcGIS.

جدول 3: مصفوفة توافقية المخرجات المصدرة مع برمجيات نظم المعلومات الجغرافية

برنامج نظم المعلومات الجغرافية الصيغة الموصى بها ملفات الإسناد المعتمدة مستوى التوافق ملاحظات التشغيل السريع

QGIS 3.x (Quantum GIS) GeoTIFF / PNG+PGW .prj + .points + .tfw 100% (توافق تام أصيل) Layer -> Add Raster Layer مع إمكانية مراجعة نقاط GCP من ملف .points.
